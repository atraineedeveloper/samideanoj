# Fazo 0: Malkovro

Fazo 0 decidas, ĉu indas konstrui la adresaron, antaŭ ol skribi eĉ unu linion de kodo. Ĉio en ĉi tiu dokumento estas **hipotezo**: ni konfirmas aŭ forĵetas ĝin per intervjuoj.

- **Celata daŭro:** 2 semajnoj.
- **Celo:** 12 kompletaj intervjuoj kaj unupaĝa dokumento reverkita surbaze de pruvoj.
- **Regulo:** neniu hipotezo transiras al fazo 1 sen almenaŭ 4 intervjuoj, kiuj subtenas ĝin.

## Privateco de la intervjuoj

La rezultoj de la intervjuoj **ne** estas publikigataj en ĉi tiu deponejo kun nomoj aŭ personaj datumoj. Ni konservas ilin private kaj publikigas nur anonimigitan sintezon.
