# Arkitekturaj decidoj (ADR)

Ĉi tie ni registras ĉiun gravan decidon pri la projekto: kion ni decidis, kial, kaj kiujn sekvojn ĝi havas. Post unu jaro ili klarigos, kial la sistemo estas tia, kia ĝi estas.

## Kiel aldoni novan decidon

1. Kopiu [`0000-sablono.md`](0000-sablono.md) kun la sekva numero kaj mallonga titolo, ekzemple `0002-elekti-datumbazon.md`.
2. Plenigu ĝin kaj malfermu kunfando-peton.
3. Akceptita decido ne estas redaktata; se ĝi ŝanĝiĝas, oni verkas novan ADR, kiu anstataŭas ĝin.
