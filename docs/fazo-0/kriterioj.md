# Kriterioj por fini la fazon

Ni pluiras al fazo 1 nur se la tri "jes"-kriterioj plenumiĝas; alie ni ĝustigas la ideon aŭ forĵetas ĝin.

| Decido | Kriterio |
| --- | --- |
| Jes | 7 el 12 personoj priskribas la problemon sen ke vi sugestu ĝin |
| Jes | Almenaŭ 4 provis solvi ĝin mem (serĉis grupojn, demandis, uzis Amikumu) |
| Jes | Almenaŭ 6 pretus krei publikan profilon kun urbo kaj unu socia reto |
| Ĝustigi | La bezono ekzistas, sed ĝi estas alia (ekzemple trovi eventojn aŭ materialojn, ne personojn) |
| Ne | La plimulto diras, ke Telegramo jam sufiĉas al ili |

## Taskoj de ĉi tiu fazo

- [ ] Revizii kaj ĝustigi la hipotezojn H1–H4
- [ ] Publikigi la varbo-mesaĝon en 3 grupoj
- [ ] Aranĝi 12 intervjuojn
- [ ] Fari kaj registri la intervjuojn
- [ ] Sintezi la trovojn kaj reverki la hipotezojn
- [ ] Decidi: jes / ĝustigi / ne
